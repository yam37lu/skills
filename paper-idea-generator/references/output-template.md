# 输出模板

默认完整版按下面顺序写；"快速版"只保留第 1、2、3、6 节，并把 idea 卡压成半页。

全文用中文，论文工作标题给中英双语。引用统一编号 `[S1]`，文末列全；报告原文用"（报告第 X 章）"标注。

## 开头：三个结论

```
最推荐：I2《……》——理由一句话（新颖性 + 数据 + 与项目契合）。
最稳：I1《……》——理由一句话（数据现成、路线成熟、MPU 明确）。
最高风险高回报：I4《……》——理由一句话（问题新，但依赖 X 数据/算力）。
```

先给结论，不要让读者翻到最后才知道推荐哪个。

## 3. 候选选题清单

每个保留方向 2-4 个选题。

| 编号 | 方向 | 工作标题（中/英） | 一句话 claim | 类型 | 最小可发表单元（MPU） | 数据 | 初判 |
|---|---|---|---|---|---|---|---|
| I1 | D1 | <中文题目> / <English title> | <在 X 条件下，用 M 比 baseline 在指标 Y 上更好，因为 Z> | 新方法 | <主实验 + 2 组消融> | <公开/自建> | 强/中/弱 |

## 4. 重点 idea 详案（3-5 个）

每个 idea 用同一张卡，标题保留编号，方便评分表引用。以下为模板。

### Idea I1：<中文工作标题> / <English working title>

**一句话 claim**

<一句话说清：在什么问题/条件下，提出什么机制，相对什么 baseline，预期在什么指标上更好，为什么。>

**问题与 gap**

<2-4 段：业务/科学问题是什么；现有做法分几类；每类为什么不够；缺口落在性能、鲁棒性、数据、评测还是部署。>

| 最近工作 | 任务/数据 | 做法 | 局限 | 与本研究的关系 | 证据级别 |
|---|---|---|---|---|---|
| [S1] <作者, venue year> | <task/dataset> | <method> | <limitation> | <提供 baseline/组件/对照> | A |
| … | | | | | |

**科学假设**

<可证伪的假设，写成"若……则……，因为……"。例如："若在匹配阶段引入全局几何一致性约束，则大场景分块接边的平面误差会下降，因为分块独立平差是误差累积的主因。"）

**技术路线**

1. **问题形式化**：输入 <X>，输出 <Y>，约束 <Z>；评价 <metric>。
2. **数据与预处理**：<来源、规模、划分、标注、增强、坐标系/分辨率统一>。
3. **方法与模块**：<baseline> → <模块 A（对应创新 1）> → <模块 B（对应创新 2）> → <联合训练/推理>。
4. **训练/推理细节**：<损失、优化器、epoch、硬件、推理耗时>。
5. **评测**：<主实验、消融、鲁棒性、效率、可视化/案例分析>。

| 阶段 | 主要工作 | 产出 | 里程碑/决策点 |
|---|---|---|---|
| M1（1-2 月） | 数据与 baseline 复现 | 可比 baseline 表 | baseline 达标才继续 |
| M2（2-4 月） | 模块 A/B 实现 | 主实验初版 | 消融有效才保留模块 |
| M3（1-2 月） | 鲁棒性/效率/跨数据 | 补充实验 | 跨数据掉点 >X% 则改写 claim |
| M4（1 月） | 写作与复现包 | 投稿稿 | — |

每条创新必须能落到一个模块、一个消融、一个对照。禁止"提出了一种融合框架"这种无法验证的表述。

|---|---|---|---|---|
| C1 | <例如：用全局几何约束替代分块独立平差> | <误差如何被约束> | <去掉约束的消融；与 baseline 比接边误差> | <大场景显存不够> |
| C2 | … | | | |

**实验设计**

| 项目 | 设计 |
|---|---|
| 数据集/划分 | <公开数据集 + 自建数据；train/val/test 比例；是否跨区域> |
| Baselines | <≥2 个强 baseline，含报告现有做法/商用引擎的可比项> |

| 消融 | <每个创新一组；模块替换/移除/顺序> |
| 鲁棒性 | <跨季节/跨传感器/跨分辨率/遮挡/噪声> |

**预期结果与 MPU**

## 写作约定

- **三类事实分开**：报告事实用"（报告第 X 章）"；文献事实用 `[S1]`；推断用"推断："或"可能"。
- **数字必须带口径**：数据集、划分、指标、单位；不同 benchmark 的数字不直接比较。
- **不写"首次/首创"**，除非完成穷尽检索并有证据；默认写"据检索未见"。
- **不写"达到 SOTA"**，写"在 <数据集> 上相对 <baseline> 提升 <区间>"。
- **每个 idea 的最近工作表至少 3 行**，其中 2 行 A 级证据。
- **快速版**：方向表 + 3 个 idea 简卡（claim、路线 3 步、创新 2 条、风险 1 条）+ 评分表。
